# Ege Şen — Portfolyö

Gömülü sistemler, yapay zeka ve robotik ile ilgilenen bir lise öğrencisinin kişisel portfolyö sitesi. Terminal / kod editörü temasında, koyu renk paleti ve yazı animasyonlarıyla hazırlandı.

## Canlı Site

Yayına alındıktan sonra buraya link eklenecek:
`https://<kullanici-adi>.github.io/<repo-adi>/`

## Kullanılan Teknolojiler

- HTML5
- CSS3 (tek dosya içinde, framework yok)
- Vanilla JavaScript (yazı animasyonu, sekme/scroll navigasyonu)

## Bölümler

- `about.js` — Hakkımda, eğitim, ilgi alanları
- `projects.json` — Projeler (Fly Bot vb.)
- `skills.yaml` — Yetenekler (seviye bazlı: İleri / Orta / Öğreniyor)
- `experience.log` — TEKNOFEST, Deneyap, BİLSEM zaman çizelgesi
- `contact.sh` — İletişim bilgileri

## İçeriği Güncelleme

Site tek bir `index.html` dosyasından oluşuyor. İçerikleri güncellemek için dosyayı bir metin editörüyle (VS Code, Not Defteri vb.) açıp ilgili metinleri değiştirmen yeterli — ayrı bir kurulum veya derleme adımı gerekmez.

## Yerelde Çalıştırma

Ekstra bir kuruluma gerek yok. `index.html` dosyasını tarayıcıda çift tıklayarak açman yeterli.
